# Folder Structure Breakdown

```text
.
├── assets/                  # Root level shared assets
│   ├── css/                 # Global stylesheets
│   ├── js/                  # Shared JavaScript libraries and custom scripts
│   ├── font-awesome/        # Icon library assets
│   ├── fonts/               # Custom and self-hosted fonts
│   ├── images/              # Images used across the site
│   └── audio/               # Audio clips used in the ecosystem
├── docs/                    # (New) Detailed project documentation
├── startups/                # Startups-specific sub-site
│   ├── assets/              # Local assets for startups site
│   ├── career.html          # Recruitment portal
│   └── index.html           # Startups showcase landing
├── index.html               # Main root landing page
├── legal.html               # Legal information
├── privacy-policy.html      # Privacy Policy
├── refund-policy.html       # Refund Policy
├── terms-service.html       # Terms of Service
├── README.md                # Project entry documentation
└── .gitignore               # Git exclusion rules
```

## Key Files
- `assets/js/grayscale.js`: Manages the root site's navigation and scroll effects.
- `startups/assets/js/application.js`: Manages behavior for the startups showcase.
- `index.html`: The hub for all ecosystem initiatives.
