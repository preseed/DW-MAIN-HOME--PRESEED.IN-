# Preseed Landing Portal

> **GitHub Description:** The central ecosystem portal for Preseed's startups and initiatives, featuring project showcases, investor relations, and semantic web research.

Preseed is a landing portal and ecosystem for Nishchal's startups and initiatives. It serves as a central hub for various projects including social networking, education, and spiritual/scientific research.

## Tech Stack
- **Frontend**: HTML5, CSS3, JavaScript
- **Frameworks**: Bootstrap 3.x
- **Libraries**: jQuery, Font Awesome
- **Integrations**: Google Analytics, Typeform, LinkedIn Embeds, YouTube Embeds, Spotify Embeds

## Repository Structure
- `/index.html`: Main landing page for Preseed.
- `/startups/`: Contains the sub-site focused on specific startup projects and investor relations.
- `/assets/`: Shared styles, scripts, and images.
- `/docs/`: Detailed project documentation (Architecture, API Flow, etc.).
- `/legal.html`, `/privacy-policy.html`, etc.: Legal and policy pages.

## Getting Started
To run the project locally, you can serve the root directory using any static web server (e.g., Live Server in VS Code, `python -m http.server`).

## Key Initiatives
1. **Chattodo**: Actionable chat app for productivity.
2. **Global Regulatory Insights**: Legal compliance startup.
3. **Metalanguage**: R&D for semantic web.
4. **Math Ed Labs**: Educational furniture and tools.
5. **Preseed Admin**: YouTube channel for community culture.

The project relies on external script integrations via CDNs and specific API keys (e.g., Google Analytics). Refer to `docs/api-flow.md` for more details.
